# Visualize the spatio-temporal cross-validation index

Visualize the spatio-temporal cross-validation index

## Usage

``` r
vis_spt_rset(rsplit, cex = 0.02, angle = 60)
```

## Arguments

- rsplit:

  rsample::manual_rset() object.

- cex:

  numeric(1). Size of the points in the plot.

- angle:

  numeric(1). Viewing angle of 3D plot.

## Value

None. A plot will be generated.
