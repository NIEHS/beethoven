# Check file status and download if necessary

Check file status and download if necessary

## Usage

``` r
feature_raw_download(path = NULL, dataset_name = NULL, ...)
```

## Arguments

- path:

  Path to qs file with all download specifications per dataset.

- dataset_name:

  character(1). Dataset name.

- ...:

  Arguments passed to
  [`amadeus::download_data`](https://niehs.github.io/amadeus/reference/download_data.html)

## Value

logical(1).
